# Dorfplatformer9 progression — native port reference

Static analysis of project.json and decoded levels. Script IDs refer to original Scratch blocks. Preserve reachable event chains; detached blocks are not executable merely because they appear in the project.

## Startup and sequential progression
Menu Title Code (#o): wait for mouse or any controller button, hide, broadcast-and-wait Intro Ani, broadcast Start Game then Neue. Intro Ani starts Time Reset. menu Neue (+x) broadcasts Restart Level. Sprite1 flag handler initializes E=1; Menu initializes ___LEVELs=0 and win=0 after 1.4 seconds.
Sprite1 Restart Level (-}): if E<7, DAMAGE=0, Level #=E, Load (wait), Tran Lev (wait), Create, start level v1, Make=0, hide and stop scripts. Otherwise broadcast Good Ending. Player body (%^) handles Player move out level & back to map by immediately broadcasting Restart Level before its glide; do not implement mandatory map visits. The map exists as a separate path; actual source target list lacks Player on map, which its sensing and save blocks reference.

## Goals and unlocks
fane (X/) and Fane+ (XD) use first type 19 position, minus camera/world offsets; Fane+ adds Plus to X and 250 to Y. Fallback (1500,0) or (1500+Plus,90). Contact with Player out while win=0 sets win=1 and emits Win. fane Win (X)) increments ___LEVELs only if Level #-1 equals ___LEVELs and ___LEVELs<6. Fane+ Win (Xw) increments E unconditionally, stops other scripts, sets win and Pause, broadcasts Still, plays Elec Piano Loop, waits 2 seconds, emits Time Reset only if Level #=4 and a____SS>0, clears a____SS, broadcasts Player move out level & back to map. Map scanning tests up to ___LEVELs+1 nodes, capped to six at completion. Space selects, E requests save. Death uses Restart Level with unchanged E, except concurrent events may affect state.

## World clock
Stage Time Reset (LA): Day=1/3, %=0, wait 6 seconds, Day=0/3, call Day1, repeat remaining days twice. Day1 increments day, clears progress and ND, 1320 daylight iterations (100/1320 progress each), sets N=1 and %=0, 100 sunset iterations (brightness -1), Timer=840, 840 night iterations (Timer -1, progress +100/840). Later days broadcast-and-wait New Day, dawn has two 50-iteration ramps (brightness -100 to -50 then 0; ND +2 then -2), then daylight/sunset/night. At third sunset ND increases by 2 each iteration. END Time emitted before third night. Game over World after last night. Most loops gate on a____SS=0, Travel=0, Pause=0. Per iteration wait max(0,0.051300000000745055-dt); actual duration requires runtime measurement. Figur3 Game over World (/b) rises from y=-200 by 0.7 until touching Died/Pipie or Player, then broadcasts Game Over Ani. Figur4 shows on expiration. Good Ending stops Stage scripts; Intro/BadEnding fades ghost +0.5 over 200 iterations then waits 1 second and invokes greenFlag. Speed Timer starts at Start Game and accumulates sensing_timer then resets it repeatedly; no pause check in this loop.

## Pipes and unusual shortcut
Levels clone (Va): type16, y+3, if TRANZ=0 switch mask to 1_15; contact Player sets _PIE # to object ID/index. Down/S/touch input 4 and Player.Fall<3 required. Level6 additionally requires first character of Day>1. Set PIX to screen X, TRANZ=1, broadcast Travel. Died/Pipie (*R) hides player, pauses, animates entry, broadcasts Trank and waits, increments _PIE #, loads next object X into Cam x, broadcasts Scroll X and waits. Destination Y>400 sets Y world=1100 else 0; subtract offset. Rebuild enemies via Setup moops, animate exit, Toi died, TRANZ=0, Pause=0. Distinguish Travel flag from Travel event and TRANZ. All 20 entrance/destination pairs in level_progression.json use 1-based source indices; destination type18. Level1 pipe index937 targets X=9999999999999972. Player Animate Cat condition Scroll x>999999999999999 sets Day=3/3, E=5 and broadcasts Win, which increments E to 6. Preserve this intentional-looking shortcut as source behavior, without claiming designer intent.

## Final boss
Dragon start level v1 (ZZ) only level6, waits for Play=1 and camera crossing >9200 (or existing Final Boss state), sets Final Boss=1, broadcasts boss, stops sound, locks Cam x=9200, repeatedly broadcasts Power Up until F. Dragon starts at (95,41), HP=3; phase1 damage -0.1/-0.3, phase2 after 1s HP=3 damage -0.01/-0.05, phase3 HP=5 and Final Boss=2. Each phase ends HP<1. Third phase special contact -3, falling stomp -1 and Yump, other contact -1 and Power down if DAMAGE=0. Ends hide, Final Boss=0, Kill sound; no direct Win in this chain. Type25 marker level6 at (9252,72). Do not assume sprite named Final Boss is the whole encounter; Dragon controls main sequence. Detached alternate HP=10 script exists but is not part of the above reachable chain.

## Save codes
Game -Save + Load serializes [code]|Phone Controls costume #|Player on map X|Player on map Y|Player on map costume #|___LEVELs|Powerup|[/code]. Load reads corresponding values, broadcasts lives/player x/player:y/player:cos with shared _______LIVES temporary, assigns unlock count and Powerup. E, Day, Timer, boss HP and camera are not serialized. Player on map target missing; exact runtime missing-target behavior must be verified. Native extended save should be versioned separately. Original export list closes with F.
